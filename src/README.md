# Source

Projetos de produção do Decor.

- `Decor.Core`: domínio e contratos centrais.
- `Decor.Application`: serviços e regras de aplicação.
- `Decor.Infrastructure`: persistência e integrações técnicas.
- `Decor.FluentSqlBuilder`: biblioteca de construção fluente de comandos SQL.
- `Decor.AvaloniaUI`: frontend multiplataforma em migração para AvaloniaUI.
